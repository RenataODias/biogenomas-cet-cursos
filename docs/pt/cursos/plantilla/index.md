# Modelo de curso

!!! info "Como usar este modelo"
    1. Copie a pasta `docs/pt/cursos/plantilla/` com um nome novo (por exemplo `docs/pt/cursos/montagem-nanopore/`).
    2. Faça o mesmo em `docs/es/cursos/` para a versão em espanhol — **o nome da pasta deve ser igual nas duas línguas**.
    3. Adicione o curso ao `nav` do `mkdocs.yml` e um card na [página de cursos](../index.md).
    4. Apague esta caixa.
