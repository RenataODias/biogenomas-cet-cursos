# Plantilla de curso

!!! info "Cómo usar esta plantilla"
    1. Copia la carpeta `docs/es/cursos/plantilla/` con un nombre nuevo (por ejemplo `docs/es/cursos/ensamblaje-nanopore/`).
    2. Haz lo mismo en `docs/pt/cursos/` para la versión en portugués — **el nombre de la carpeta debe ser igual en los dos idiomas**.
    3. Agrega el curso al `nav` de `mkdocs.yml` y una tarjeta en la [página de cursos](../index.md).
    4. Borra esta caja.
